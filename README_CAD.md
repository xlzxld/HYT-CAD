# 热流道自动化 — AutoCAD 出图脚本 使用手册

一套在 AutoCAD 里自动绘制**热流道分流板、出线槽、加热条**的 LISP 工具箱。
装一次，以后每次打开 CAD 顶部菜单栏自动出现「热流道自动化(R)」，点菜单或敲命令出图。

> 适用版本：AutoCAD 2007 ~ 2026 全系列（**不含 AutoCAD LT**——LT 的 LISP 没有 COM 接口）。
> **按版本选文件（重要）**：AutoCAD **2021 及以上**用 `scripts\` 里的脚本（UTF-8 编码）；
> AutoCAD **2007 ~ 2020** 必须用 `scripts_ansi\` 里的同名脚本（GBK 编码，拷贝时覆盖到 `scripts\` 再加载）——
> 新版 CAD 读旧编码会乱码，旧版 CAD 读 UTF-8 会直接报「错误: 输入中的点位置不正确」无法加载。
> 当前版本：offset_runner v10.6 / slot_runner v10.3 / jrt_runner v9.14 / dt_start **v2.9**
> （v2.9 = 低版本安装报错修复，AutoCAD **2007 实测通过**；详见第 7 节「版本兼容」）。

---

## 1. 文件清单（每个文件是干什么的）

目录结构：`scripts\` = 脚本+配置+运行生成物（一个运行单位，勿拆散）；`tools\` = 开发者工具；根目录 = 两份文档。

| 文件 | 作用 | 能删吗 |
|---|---|---|
| `scripts\dt_start.lsp` | **总管**：一键加载其余三个脚本 + 写开机自启 + 挂顶部菜单 | 不能删 |
| `scripts\offset_runner.lsp` | 分流板绘制（OFF 命令）：偏移/裁剪/圆角/封口/螺丝/倒角/假体/热咀 | 不能删 |
| `scripts\slot_runner.lsp` | 出线槽绘制（SLOT 命令）：通道壁/裁剪/大小圆角/封闭/CXK 分流 | 不能删 |
| `scripts\jrt_runner.lsp` | 加热条绘制（JRT 命令）：多层嵌套轮廓/端帽/出线口 | 不能删 |
| `scripts\offset_runner.ini` | 分流板**参数默认值**（记事本可改，详见第 6 节） | 可删（回内置默认后重新生成） |
| `scripts\slot_runner.ini` | 出线槽参数默认值 | 同上 |
| `scripts\jrt_runner.ini` | 加热条参数默认值 | 同上 |
| `scripts\*_mem.ini`（3 个） | 参数**记忆**：自动记录你上次在参数窗口填的值和选的模板 | 可删（忘掉记忆，从默认重新开始） |
| `scripts\*.dcl`（3 个） | 参数窗口界面文件，**运行时自动生成** | 可删（自动重建） |
| `tools\_audit.py` | 开发者用：脚本静态审计（同名函数覆盖/死函数检测） | 与使用无关 |
| `tools\check_lisp.py` | 开发者用：括号/编码/规范校验 | 与使用无关 |
| `tools\_collide.py` | 开发者用：脚本同名函数冲突检测 | 与使用无关 |
| `tools\check_sysvars.py` | 开发者用：低版本系统变量兼容门禁 | 与使用无关 |

## 2. 安装（只需一次）与日常使用

### 安装
1. 打开 AutoCAD，命令行输 `APPLOAD`，选择 **`scripts\dt_start.lsp`**，加载；
2. 命令行输 `DTINSTALL`；
3. 完成。以后每次开 CAD：三个脚本自动加载 + 顶栏自动出现「热流道自动化(R)」菜单。

### 日常使用
点顶栏菜单，或直接敲命令，两者等价：

| 菜单项 | 命令 | 干什么 |
|---|---|---|
| 分流板▸画分流板 / 分流板参数 | `OFF` / `PARAM` | 画整块分流板（先选模板：通用 / 矩形） |
| 加热条▸画加热条 / 加热条参数 | `JRT` / `JRTPARAM` | 画加热条（先选模板：通用一 / 通用二） |
| 出线槽▸画出线槽 / 出线槽参数 | `SLOT` / `SLOTPARAM` | 画出线槽（弹参数框→全自动） |
| 工具▸重载脚本 | `DTRELOAD` | 换新脚本后不重启 CAD 刷新 |
| 工具▸安装自启 / 卸载工具箱 | `DTINSTALL` / `DTUNINSTALL` | 装 / 卸自启动（卸载=菜单/钩子/路径全还原） |
| 工具▸诊断 | `DTDBG` | 加载/对话框报错时排查 |
| 工具▸打开脚本目录 | — | 资源管理器打开本文件夹 |

换电脑部署：把**整个 CAD 文件夹**（含 scripts/tools 子目录）拷过去。
- 新电脑是 **AutoCAD 2021 及以上**：直接 APPLOAD + DTINSTALL 一次即可；
- 新电脑是 **AutoCAD 2007 ~ 2020**：先把 `scripts_ansi\` 里的 4 个 .lsp 复制到 `scripts\` **覆盖同名文件**，再 APPLOAD + DTINSTALL（这步只做一次；ini/dcl/记忆文件两种版本通用，无需处理）。

## 3. 画图流程（step by step）

### 第一步：画源线
| 要画的图 | 源线图层 | 画什么 |
|---|---|---|
| 分流板 + 假体 + 加热条 | **LD** | 流道中心线（直线/圆弧均可） |
| 出线槽 | **CX** | 出线槽中心线 |
| （可选）垫片 | **DP** | 垫片轮廓——要在跑 SLOT **之前**画好，用于出线口分流 |

### 第二步：画分流板 `OFF`
1. 菜单「分流板▸画分流板」→ 弹**模板选择框**：
   - **通用**：标准全流程（偏移+裁剪+圆角+封口+螺丝+倒角+假体+热咀）；
   - **矩形**：LD 范围外扩画矩形板边+四角倒角+圆角矩形假体（画完会删 LD 源线）；
2. 弹**参数框** → 数值确认或修改 → 确定 → 全自动；
3. 跑完看命令行统计，失败处图上有文字标注。

### 第三步：画出线槽 `SLOT`
1. 「出线槽▸画出线槽」→ 参数框 → 确定；
2. 自动：偏移通道壁 → 裁剪 → 小圆角 → 延长 → 收头 → 大圆角 → 封闭敞口 → 分流 CXK → 删源线；
3. **重跑须知**：源线已被上一次自动删除，需重画 CX 源线；CX/CXK 层旧产物手动删掉。

### 第四步（需要时）：画加热条 `JRT`
1. 「加热条▸画加热条」→ 选模板：
   - **通用一**：用 LD 源线 + OFF 跑出的 RZ 热咀圆（所以要先跑过 OFF）；
   - **通用二**：用 **JRT** 图层源线 + **JRTDW** 图层定位线；
2. 参数框 → 确定 → 自动生成多层嵌套加热条轮廓。

## 4. 命令手册

| 命令 | 说明 |
|---|---|
| `OFF` | 分流板全流程。先弹模板框（取消=不执行），再弹参数框 |
| `PARAM` | 只开分流板参数框，不执行 |
| `SLOT` | 出线槽全流程。弹参数框，确定后执行 |
| `SLOTPARAM` | 只开出线槽参数框 |
| `JRT` | 加热条全流程。先弹模板框，再弹参数框 |
| `JRTPARAM` | 只开加热条参数框 |
| `DTRELOAD` | 目录里的 .lsp 换新后，不重启 CAD 重新加载（顺带重挂菜单） |
| `DTINSTALL` | 写开机自启 + 加入支持路径（换电脑/换目录后重跑一次） |
| `DTUNINSTALL` | 彻底卸载：菜单/钩子/路径全部还原，CAD 配置恢复原样 |
| `DTDBG` | 诊断：打印目录定位、参数对话框链路的逐步状态，报错时把输出发维护者 |

## 5. 图层对照表（跑完后图上有什么）

| 图层 | 颜色 | 内容 | 谁管理 |
|---|---|---|---|
| LD | — | 分流板/假体/加热条中心线（源线） | 你画 |
| FLB | 红 | 分流板轮廓（含封口线、倒角） | OFF |
| LS | 青 | 螺丝孔 | OFF |
| JT | 洋红 | 假体轮廓 | OFF |
| RZ / DK | 橙 / 白 | 热咀圆 / 点孔圆（同心） | OFF |
| DP | 蓝 | 垫片（你手画，脚本永不清理） | 你画 |
| CX | 蓝 | 出线槽（壁、圆角、封闭线；源线跑完自动删） | SLOT |
| CXK | 蓝 | 距垫片最远的那条出线槽封闭线（自动分流） | SLOT |
| JRT | 黄 | 加热条多层轮廓 + 端帽 | JRT |
| JRTDW | — | 通用二加热条的定位源线 | 你画 |

临时层（FBX/JTFBX）跑完自动并入正式层消失，图层栏只留下表内图层。

## 6. 配置文件详解（改默认值看这里）

三个 `.ini`（在 `scripts\` 里，与脚本同目录——ini/记忆/界面文件都是脚本的运行单位，勿分开存放）就是各脚本的**参数默认值**，记事本打开直接改，保存后**下次打开参数窗口立即生效**（不用重启 CAD、不用重载脚本）。参数窗口的「恢复默认」按钮恢复的就是 ini 里的值；**删掉 ini** = 回代码内置默认（会自动重新生成）。

> 注意：ini 里的值会被 `_mem.ini` 的记忆值覆盖（你点过"确定"的值优先）。想彻底回到默认：删 ini + 删 mem。
> 编辑保存请保持 **ANSI 编码**（记事本默认即是，勿改存 UTF-8，否则中文节名匹配失败、配置静默失效）。

### 6.1 offset_runner.ini（分流板，按模板分节）

**[通用] 节** —— 通用模板参数：

| 参数 | 默认 | 含义 |
|---|---|---|
| offset_dist | 35 | 流道中心线向两侧偏移距离（通道半宽+让位，决定 FLB 轮廓宽度） |
| hole_dist | 50 | 假体轮廓距流道中心线距离（决定假体大小，需大于 offset_dist） |
| hole_extend | 15 | 假体封闭线端头延长量（传统假体流程用） |
| fillet_r | 15 | 分流板断口圆角 R（不足自动递减） |
| fillet_r_hole | 15 | 假体断口/封口圆角 R |
| chamfer_d | 5 | 封口端部 45° 倒角距离 |
| screw_in | 10 | 螺丝孔中心向内偏移距离 |
| screw_r | 4.25 | 螺丝孔半径 |
| nozzle_offset | 40 | 热咀圆心距封口线距离（沿通道向内） |
| nozzle_r | 11.35 | 热咀圆半径 |
| pin_r | 3 | 点孔半径，**设 0 不画点孔** |

**[矩形] 节** —— 矩形模板参数（含义同上，未列出的用通用节值）：offset_dist / hole_dist / fillet_r_hole / screw_in（矩形默认 15）/ screw_r / nozzle_r / pin_r / **rect_chamfer**（板边四角 45° 倒角，默认 10）。

**[假体] 节** —— 全局开关：

| 参数 | 默认 | 含义 |
|---|---|---|
| envelope | 0 | 假体绘制方式：**0 = 传统逐步**（默认）；**1 = 包络法**（FLB 包络盒外扩整体圆角矩形，适合对头相接类布局）。与参数框「假体用包络法」勾选框联动，勾选后点确定会被记忆（优先于本文件） |

### 6.2 slot_runner.ini（出线槽，单节 [参数]）

| 参数 | 默认 | 含义 |
|---|---|---|
| slot_dist | 17.5 | CX 源线向两侧偏移距离（通道半宽） |
| slot_extend | 50 | 悬空端头固定延长距离（用于与相邻通道壁相交） |
| slot_fillet_r_small | 15 | 通道壁相交断口小圆角 R（空间不足内部自动递减） |
| slot_fillet_r_large | 30 | 延长交会处大圆角 R（同上） |

### 6.3 jrt_runner.ini（加热条，按模板分节）

**[通用一] 节**：

| 参数 | 默认 | 含义 |
|---|---|---|
| jrt_offset | 29 | 加热条单侧宽度（半宽） |
| jrt_cap_inset | 11 | 直线端帽封闭线内偏距离 |
| jrt_fillet_r | 19 | 交汇断口圆角 R（内层逐层递增、同心） |
| jrt_cap_r | 29 | 封闭线圆角 R（≥半宽时为相切圆弧） |
| jrt_inner_step | 4 | 相邻内层轮廓间距 |
| jrt_inner_count | 2 | 内向偏移次数（总层数 = 次数 + 1） |

**[通用二] 节**（两点式，只列它用到的）：jrt_inner_step / jrt_inner_count 含义同上；**jrt2_neck_len**（65，出线颈线长度）、**jrt2_neck_off**（35，颈线偏移）、**jrt2_close_r**（15，出线封口圆角）、**jrt2_trim_r**（15，出线相交圆角）。

## 7. 注意事项与已知限制

- **重跑 OFF**：直接重跑，旧产物自动清理。矩形模板跑完会删 LD 源线（与画图同撤销组，一次 Ctrl+Z 找回）；通用模板不删。
- **重跑 SLOT**：源线上次已自动删除需重画；CX/CXK 旧产物手动删。
- **重跑 JRT**：自动清理重画。
- **大圆角已知行为**：两面墙"对头相接"（延长后迎面碰在同一点、方向近于平行）的交点不做大圆角——这是 v9.5 定案的既有行为。这类布局如需圆角，用参数框勾选「假体用包络法」换包络假体方案。
- **OFF/JRT 每次先弹模板选择框**，点取消即不执行。
- 图层名一字不差；已存在小写同名图层会被自动纠正为大写。
- 圆弧中心线大部分情况支持；每步结果看命令行统计，失败处有文字标注。
- 无垫片跑 SLOT 正常，只是不分流 CXK。
- **版本兼容**：2007~2026 全系列通用（**AutoCAD 2007 已于 2026-08-31 实测通过**：安装、自启、菜单、三个命令全跑通）；**LT 不支持**。
  - 2016 前的版本没有 `TRUSTEDPATHS` 这个安全机制，安装时会打印「无(老版本, 跳过)」，**属正常现象**，不影响使用（v2.9 已修复该变量在老版本上导致的安装报错）。
- **编码须知**：2007~2020 的 CAD 只能加载 GBK 编码脚本（`scripts_ansi\` 目录），2021+ 只认 UTF-8 编码（`scripts\` 目录）——拷贝部署时按上面"换电脑部署"选对文件即可，其余使用方法完全相同。
  - 编码选错的表现是**加载**时就报「错误: 输入中的点位置不正确」；而 v2.9 之前在老版本上 `DTINSTALL` 报的「参数类型错误: stringp nil」是另一回事（低版本系统变量兼容问题），换正确编码的文件 + 用 v2.9 即解决。
- 每次 APPLOAD 重载后参数回默认值（记忆文件在则恢复上次值）。

## 8. 出问题了怎么办

1. **加载/菜单/对话框类**：跑 工具▸诊断（`DTDBG`），把命令行全部输出发维护者（老版本安装报错时，重点看输出开头的 `[0z]` 段——它会列出当前 CAD 缺哪些系统变量）；
2. **几何类**（画的形状不对）：发 **截图 + DXF**（`SAVEAS` → AutoCAD 2007 DXF），从坐标直接定位；
3. **想彻底重来**：`DTUNINSTALL` 卸干净 → 删 ini/mem → 重新 APPLOAD + DTINSTALL。
