# CAD 热流道 LISP 工具箱 — 全面梳理与修复计划

已通读全部代码（4 个 .lsp 共 6679 行 + tools 3 个 .py + 4 个 ini），并核对项目自带校验器逻辑。以下按「问题清单 → 修复措施 → 验证方案 → 版本/文档」组织。

## 一、问题清单（定位 / 原因 / 严重程度）

### P0 高（当前版本活性缺陷，会崩溃）
1. **slot 文字标注崩溃链**（slot_runner.lsp）：`dt:fillet-pair` 半径递减时在 CX 层写 `Rn` 标注文字（L650-656）；而 `dt:collect-heads`(L663)、`dt:collect-ends`(L748) 不按类型过滤，`slot-extend-fixed`(L886)、`slot-join`(L970/L1007)、`slot-close`(L1067)、`slot-fillet-all`(L810) 对整层收集后直接 `vlax-curve-getstartpoint(text)` → 未捕获异常 → SLOT 中途终止。
   原因：v10.2 曾加 `slot-curve-p` 防护，但 v10.2 因 slot-join 括号错位被整体回退，防护随之丢失，v10.1 未补回（AGENTS 版本史 L212 实锤）。
2. **offset LD 层含文字/块即崩溃**：`dt:close-channels`(L1034-1048 对 center-lines 直接 getstartpoint)、`dt:extend-ends`(L1276-1278) 未过滤源线类型。v10.2b 只修了 FBX/JT 侧，LD 侧漏修。
3. **offset 三个入口重跑崩溃**：`dt:chamfer-close`(L1230)、`dt:fillet-close`(L1414)、`dt:drill-holes`(L1669) 对 FBX/JTFBX 全量迭代；独立重跑时上次失败标注文字（mark-fail 写入同层）会被当封口线处理 → 崩溃。
4. **jrt LD 层含文字即崩溃**：`dt:jrt-touch-p`(L917-924)、`dt:jrt-free-ends`(L938) 直接对 LD 全量对象调 vlax-curve（无 catch、无过滤）；其余 jrt 路径均有防护，唯此两处漏。

### P1 中（健壮性缺口）
5. **资源释放**：所有 ini/dcl 文件读写（`*-cfg-read/gen`、`*-mem-save`、`*-write-dcl`、dt_start `st-write-hook/st-remove-hook`）的 `open` 与 `close` 之间无异常兜底，异常时句柄泄漏（读句柄滞留可能令后续同路径写打开失败）；`load_dialog` 无 catch，`start_dialog` 异常时 `unload_dialog` 跳过 → 对话框句柄滞留。
6. **边界**：`dt:cut-params` 多段线分支 `vlax-curve-getparamatpoint` 对浮点偏移点可能返回 nil，nil 进入 `vl-sort` 报 bad argument type（交点恰在顶点/高曲率处触发）。
7. **隐藏跨脚本耦合**：slot 的 `dt:fillet-pair` 缺省回退 `(if (null r-start) (setq r-start *dt-fillet-r*))`(L593) 用的是 **offset 的全局**，缺省层 `"FLB"`(L592) 也是 offset 的层；slot 单独加载且直接以 nil 调用时 `> nil 0` 报错。应回退 slot 自己的 `*dt-slot-fillet-r-small*` / `"CX"`（slot 流程恒传实参，故现为潜伏）。
8. **UNDO 组悬挂**：三个 c: 命令的局部 `*error*` 只打印，不闭合流程中打开的 `UNDO BE` 组。

### P2 中低（性能 / 隐性缺陷）
9. **性能瓶颈**：`dt:cross-points`（三脚本同）O(n²) 次 COM `vla-intersectwith`，几百条通道壁的压力场景将到分钟级；`dt:pair-heads` O(n²) 纯 LISP（可接受）。
10. **参数校验**：对话框/ini 接受负值与极端值（distof 只查合法性不查范围），负 slot_dist/超大 chamfer 静默画出退化几何。
11. **疑似不一致（只标注不改）**：offset 传统假体路径 `(dt:fillet-all offset-dist hole-layer)`(L2451) 用 35 做 JT 圆心区域校验而 JT 壁偏移是 50（slot/jrt 均用各自宽度）。改动会改变几何判定行为，无 CAD 实测不安全 → 本次仅在报告中标注。

### 冗余/重复/不可达（梳理结论）
- **无死函数、无不可达代码**（95+63+88+27 个 defun 逐一核对引用）。
- 28 个库函数在 3 脚本逐字复制 ×3、7 个函数 ×2 —— 属 AGENTS §1 声明的架构约定（自包含可单独加载），已逐一比对**无漂移**，`_collide.py` 提供守护 → **保留，不合并**（合并会破坏独立加载约定）。
- 小冗余：slot L659-662 重复注释块 → 删。文档漂移：AGENTS 称参数表 11 项实为 12 项、c:OFF 行号已漂移 → 随文档同步修正。
- **并发**：AutoLISP 单线程 + 非 propagate 全局按文档命名空间隔离，无竞争面；`vl-propagate` 仅用于目录/守卫标志，安全（报告说明，不适用项）。

## 二、修复措施（每处均为小步精确 Edit，遵循坑 #44/#45）

**原则：几何行为零变化** —— 所有修复只加"类型过滤/异常兜底/缺省值纠正"，不动任何几何公式与判定规则。

1. **类型防护（P0，根治点收敛在收集函数）**：
   - 三脚本 `dt:collect-heads`、slot/offset `dt:collect-ends`、offset `dt:collect-plate-ends`（已滤，保持）循环内加 objectname 白名单过滤（Line/Arc/LWPolyline/Polyline）——一处修复覆盖全部崩溃消费点；
   - offset：`close-channels`/`extend-ends` 的 LD 收集、`chamfer-close`/`fillet-close`/`drill-holes`/`trim-all`/`fillet-all` 的图层收集加同款过滤；
   - slot：`slot-trim`/`slot-fillet-all`/`slot-join`/`slot-extend-fixed` 的 layer-vlas 后加过滤；
   - jrt：`c:JRT` 第 1 步 `(setq ld (dt:layer-vlas "LD"))` 后过滤一次（touch-p/free-ends/decide 全部受益）。
2. **异常兜底（P1）**：cfg-read/mem-save/cfg-gen/write-dcl/st-write-hook 在 catch 块后追加 `(if f (vl-catch-all-apply 'close ...))` 式无条件收尾；三对话框链 `load_dialog` 包 catch、`start_dialog` 包 catch 且保证 `unload_dialog` 执行；三个 c: 命令 `*error*` 内 catch 包裹补 `_.UNDO E`。
3. **防御校验（P1/P2）**：`cut-params` 多段线分支对 `getparamatpoint` 包 catch 并 `vl-remove-if 'null` 后再排序；slot `fillet-pair` 缺省值改 `*dt-slot-fillet-r-small*`/`"CX"`；对话框 apply 增加非负下界校验（距离/R 类参数 <0 回退当前值，仅 4 行/脚本）。
4. **性能（P2）**：三脚本 `dt:cross-points` 加包围盒预过滤（每对象一次 `vla-getboundingbox`（复用/新增 `dt:rect-bbox` 双绑定兼容解包，slot/jrt 各补一份逐字库副本），纯 LISP 求交测试，bbox 不相交才调 intersectwith）。数学上安全（bbox 不相交⇒无交点），标注"需 CAD 压力回归"。
5. **冗余清理**：删 slot L659-662 重复注释。

## 三、验证方案

1. **静态（本机可执行）**：`check_lisp.py` ×4 全绿（括号 stack/BOM/if 超限/代码区非 ASCII）、`_audit.py`（无新增全局泄漏/死函数）、`_collide.py`（同名函数仍逐字一致）、修改函数逐 defun 括号扫描（坑 #44）、修复点 grep 断言清单。
2. **边界/异常场景推演矩阵**（写入报告，逐项列修复前后行为）：pin_r=0、slot_dist=0、对话框输入 abc/-5、LD/CX 层混入文字与块、闭合多段线、零长线、R 递减到底、ESC 中断后 UNDO 状态、ini 损坏/UTF-8 误存、mem 重复节。
3. **压力场景**：报告附 CAD 内计时脚本（用户执行）：100/300/500 条 CX 源线跑 SLOT 前后耗时对比（预期 bbox 预过滤后 intersectwith 调用量从 n² 降为近似 k²·邻接数）。
4. **用户 CAD 实测清单**：APPLOAD+DTRELOAD → OFF(通用/矩形)/SLOT/JRT(通用一/二) 全流程 + 上述异常场景抽样；几何问题按坑 #33 给 DXF 复算定位。
